== A small 3D graphics processor

Pineapple is a programmable 3D graphics processor on a Digilent Nexys A7 FPGA board. It runs vertex and fragment shaders, turns triangles into pixels, tests depth, and samples textures. The picture is 320 by 180 and leaves the board over HDMI. A pineapple and a cube have both been drawn on the hardware.
